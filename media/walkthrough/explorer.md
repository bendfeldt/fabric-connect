# Browse Fabric

Click the **Fabric** icon in the Activity Bar: **Configuration** (account,
tenant, compute), **Repo** (your working tree, runnable on Fabric),
**Lakehouses** (attach them to a notebook) and **Connections**. The
**Fabric** view in the Explorer side bar browses capacities, workspaces
and items. Browsing is
read-only:

- **Capacities** → workspaces → items by type
- Lakehouse **Files** and **Tables** in OneLake
- **Connections**

Right-click for: preview a table or file, copy IDs, OneLake paths or SQL
connection strings, open in the Fabric portal, or **Pull into Repo** — a
one-time copy of an item's definition into `<name>.<Type>/`. Nothing syncs
back.

Hover any GUID in an editor to see which workspace or item it is.
